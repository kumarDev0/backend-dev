# 🥋 Sumo-Search

> ⚡ A simple CLI tool to **count**, **search**, and **check** words in any file.

---

## 🚀 Installation

🌍 Install globally using npm
```bash
npm install -g sumo-search
```

📦 Install as a project dependency
```bash
npm install sumo-search
```

🛠️ Install as a dev dependency
```bash
npm install --save-dev sumo-search
```

⚡ Run directly without installing using npx
```bash
npx sumo-search ./file.txt
```

---

## 🎯 Usage

📋 Show all words count
```bash
sumo-search ./file.txt
```

🔍 Search specific word count
```bash
sumo-search ./file.txt for
```

✅ Check if word exists in file
```bash
sumo-search ./file.txt for --exists
```

---

## 🚩 Flags

| Flag | Description |
|------|-------------|
| `--exists` | Check if a word exists in the file |
