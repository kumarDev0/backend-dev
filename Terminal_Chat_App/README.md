# black-terminal-greenChat

> A simple real-time chat tool for your terminal using only Node.js built-in modules.

---

## Installation

Install globally using npm

```bash
npm install -g black-terminal-greenChat
```

Run directly without installing using npx

```bash
npx black-terminal-greenChat
```

---

## Usage

Open two terminals and run in both

```bash
black-terminal-greenChat
```

Enter your name and start chatting

```bash
Your name: Alice
```

---

## Commands

| Command | Description |
|---------|-------------|
| Type anything + Enter | Send a message |
| `/exit` | Leave the chat with a goodbye message |

---

## Requirements

- Node.js v18+
